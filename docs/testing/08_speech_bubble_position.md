# 말풍선 위치 검증

## 테스트 목적

일반 위치와 화면 가장자리에서 말풍선이 적절한 방향으로 배치되고, 시각적 화면 영역을 벗어나지 않는지 확인한다.

## 검증 환경 및 절차

- 기준 커밋: [`2517f9b`](https://github.com/CHOIJIHWANcheese/Moni/commit/2517f9bcf3756ec489c6be28cbad03e8af94fe84)
- 환경: Windows 11 x64, Microsoft OpenJDK 25.0.5.1, JavaFX 25
- 절차: `SpeechBubblePositionerTest` 4개를 `gradlew clean test`에서 실행하고, 저장소 밖 임시 하네스로 일반 위치를 추가 확인했다. 경계 비교는 1000×800 가상 시각 영역과 220×110 말풍선을 사용했다.
- 예상 결과: 공간이 있으면 캐릭터 위에 중앙 배치하고, 좌우/상하 경계에서는 가능한 방향을 선택하거나 말풍선 좌표를 제한해 전체 영역 안에 둔다.

## 발견된 문제 및 결론

발견된 문제 없음. 위치 계산 4개 JUnit 사례와 일반 위치 하네스가 통과했다. 여러 실제 모니터의 서로 다른 배율과 운영체제별 팝업 렌더링은 확인하지 않았다.
