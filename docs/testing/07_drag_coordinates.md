# 드래그 좌표 계산 검증

## 테스트 목적

마우스 화면 좌표에서 고정 앵커를 빼 스테이지 좌표를 계산하는 규칙을 확인하고, 실행 중 실제 창 이동 여부를 점검한다.

## 검증 환경 및 절차

- 기준 커밋: [`2517f9b`](https://github.com/CHOIJIHWANcheese/Moni/commit/2517f9bcf3756ec489c6be28cbad03e8af94fe84)
- 환경: Windows 11 x64, Microsoft OpenJDK 25.0.5.1, JavaFX 25
- 절차: 기존 `MoniDragControllerTest`와 저장소 밖 임시 좌표 하네스를 실행했다. 이후 `gradlew run`으로 앱을 표시하고 컴퓨터 사용 도구로 실제 드래그를 한 번 시도했다.
- 예상 결과: 화면 좌표에서 앵커 (64, 30)를 빼서 스테이지 좌표를 계산한다. 화면 밖을 향하는 음수 좌표도 계산 결과에 그대로 반영된다. 드래그하면 창이 포인터를 따라 이동한다.

| T07-05 | 화면 경계에서 실제 드래그 | 경계 동작 확인 | 미실행 |

## 발견된 문제 및 결론

좌표 계산은 양수와 음수 사례에서 통과했다. 실제 포인터 추적 및 화면 경계에서의 드래그 동작은 확인되지 않아 판정 불가/미실행으로 남겼다. 좌표 계산 함수 자체는 화면 경계로 값을 제한하지 않는다.
