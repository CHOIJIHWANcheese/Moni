# Moni

Moni is a JavaFX desktop application targeting JDK 25 LTS and JavaFX 25.

## Requirements

- JDK 25 LTS

## Run

```powershell
.\gradlew.bat run
```

## Test

```powershell
.\gradlew.bat test
```

The initial window displays `Moni Project` only.
